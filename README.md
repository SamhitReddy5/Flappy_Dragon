# Flappy Dragon (Unity Game)

Flappy Dragon is a 2D arcade-style game inspired by Flappy Bird, developed using Unity. The player controls a dragon that must navigate through obstacles by timing jumps precisely. The project demonstrates core mechanics such as input handling, physics-based movement, and collision detection.

## Features

* Tap/keypress-based jump mechanic
* Continuous obstacle spawning
* Collision detection and game over system
* Score tracking based on progress
* Simple and responsive controls

* Unity (Game Engine)

## How to Run

### Play the Game

1. Open the `Build/` folder
2. Run the `.exe` file

### Open in Unity

1. Open Unity Hub
2. Click "Add Project"
3. Select this folder
4. Open and run the main scene
